# Outlands WOW

This repository preserves a sanitized source and operations kit for rebuilding the Living Azeroth World of Warcraft 3.3.5a server later. Download [outlands-wow-source-20261109.zip](outlands-wow-source-20261109.zip) and verify it with [SHA256SUMS](SHA256SUMS). The ZIP contains 122 source, script, SQL, configuration, test, documentation, and retained license files in their original folder structure. Its timestamps and file ownership metadata are normalized.

Read [REBUILD.md](REBUILD.md) before using the kit and [THIRD_PARTY.md](THIRD_PARTY.md) before combining upstream components. This is a source snapshot, not an installable or tested server release. The original game client/assets, databases, player/account data, live backups, logs, secrets, chat/prompts, private access policy, and host metadata are excluded. Some example identifiers and zero-filled fingerprints must be replaced and validated in an isolated rebuild.

No license is assigned to the kit as a whole. Third-party license texts remain inside the ZIP.
